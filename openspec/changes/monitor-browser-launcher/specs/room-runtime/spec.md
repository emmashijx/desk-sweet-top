# Spec Delta

## Purpose

为可交互房间提供可在本机运行的最小桌面基础，确保独立图层、可配置的布局和同步点击区域能够被后续组件复用，并保持操作体验中没有系统原生桌面图标。

## ADDED Requirements

### Requirement: 独立图层与统一布局

房间 SHALL 使用 V3.22 独立素材，按布局配置渲染位置、尺寸、层级和可见状态，并按相同坐标变换计算组件的命中区域。不得将合成房间整图作为全部家具的固定交互背景。

#### Scenario: 房间窗口尺寸变化
- **WHEN** 用户调整房间测试窗口的大小
- **THEN** 墙纸、护墙板和地板自适应铺满内容区域，不出现留白；家具维持原有比例、完整显示，显示器的可点击区域和选择界面仍与实际屏幕位置对齐。

#### Scenario: 修改显示器布局配置
- **WHEN** 显示器在布局配置中的位置或比例变化
- **THEN** 显示器素材、屏幕选择界面及命中区域同步变化，其他物件保持其配置位置。

### Requirement: 本地测试入口

系统 SHALL 提供可在 macOS 本机构建并启动的原生测试应用，用户可在正常应用窗口和全屏房间中测试显示器组件，并可使用系统应用切换及退出方式离开。

#### Scenario: 本地启动
- **WHEN** 用户按照说明执行构建与启动命令
- **THEN** 房间窗口显示 V3.22 的构图，显示器可交互，其他家具暂仅作为视觉素材展示。
